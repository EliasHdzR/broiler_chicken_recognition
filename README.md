## Para Entrenar el Modelo de YOLO

Para poder entrenar el modelo de YOLO a utilizar, es necesario modificar las rutas ABSOLUTAS el archivo ubicado en train/train.yaml.
Las rutas deben de ser ABSOLUTAS, ya que la configuración de ultralytics define la ubicación de los datasets a utilizar en una ruta específica del equipo y para poder sobreescribir este comportamiento se tienen que definir rutas ABSOLUTAS.
